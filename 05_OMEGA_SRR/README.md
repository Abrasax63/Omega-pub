# Module Omega-SRR

Espace réservé à la littérature, aux définitions et aux recherches propres à Omega-SRR.

Les sources externes doivent être référencées précisément. Les analogies, hypothèses testables et résultats démontrés doivent être distingués.

Aucune relation avec CCS ou les autres modules n'est présumée.
