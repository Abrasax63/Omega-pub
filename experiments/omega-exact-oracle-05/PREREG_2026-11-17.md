## Solveur mathématique exact — sans politique apprise

Pour un masque de croyance S de n hypothèses, soit `F(S)` la somme minimale des coûts sur les n machines supposées équiprobables (numérateur de l'espérance, entier).

- `F(S)=0` pour un singleton ;
- sinon, pour chaque sonde q **qui scinde réellement S** en deux sous-ensembles non vides S0 et S1, calculer
  `F_q(S)=n*c(q) + F(S0) + F(S1)` ;
- `F(S)=min_q F_q(S)`, politique correspondante avec tie-break lexical fixe des mots.

Preuve prévue : induction sur n ; toutes les requêtes valides donnent une bipartition, tous les sous-problèmes sont strictement plus petits ; une première question sans séparation ne peut améliorer l'optimum puisque son prix est strictement positif. Prior uniforme sur les 16 hypothèses et prix déterministe. Cette définition ne dépend **ni de récompense entraînée ni de la machine cachée**.

L'optimisation peut utiliser memoization sur des masques entiers et une borne inférieure de code binaire sur l'espérance du nombre de questions. **Toute borne d'élagage doit être mathématiquement valide** et ne pas changer le minimum. Tie-break stable : le plus petit mot lexicographique parmi les ex æquo. Une famille de masques impossibles à distinguer sur le menu produit `INDISTINGUISHABLE` plutôt qu'un faux certificat.

La comparaison principale se fait **à horizon d'identification non borné** pour rester exactement compatible avec cette relation de Bellman. Pour comparer au plafond expérimental des PR antérieures (**12 sondes**), évaluer séparément la profondeur maximale de l'arbre optimal et de `PRICE_AWARE` ; **si une politique dépasse 12**, sa comparaison `BUDGET_12` n'est pas une comparaison de deux méthodes identifiant toutes les machines dans le même budget, et doit être étiquetée non comparable. Aucun échec tronqué n'est compté comme gain de coût.
