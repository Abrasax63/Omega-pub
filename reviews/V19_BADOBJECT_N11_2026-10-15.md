# V19 — Relèvement paire → mauvais objet : audit exact des cinq premières ruptures N=11

Date : 15 octobre 2026

## 1. Verrou

La région de coexistence des **paires** est déjà complètement factorisée. Le niveau suivant est l'application

`p={x,y} → B_p → sh(B_p)`.

Deux paires peuvent produire le même mauvais objet ; les circuits positifs vivent sur les mauvais objets distincts et non sur les paires elles-mêmes.

## 2. Signature affine canonique

Les contraintes forcées sont affines sur `F_2` et s'écrivent `F c=b`. Pour une paire `p={x,y}` à `L=3`, ajouter

`c_x=c_y`, `c_{Tx}=c_{Ty}`, `c_{T²x}=c_{T²y}`.

La nouvelle brique `BR-OBS-BAD-01` canonise le système augmenté par une RREF sur les colonnes `(coefficients,rhs)`. Pour tout mauvais objet non vide,

`B_p=B_q ⇔ Sig_F(p)=Sig_F(q)`.

Le second membre affine est indispensable : le supprimer confondrait des contraintes de parités opposées.

Les nombres `42,36,36,37,38` coïncident exactement avec le document historique.

Tous les mauvais objets considérés ont codimension relative 3. Une fibre de mauvais objet contient ici une ou deux paires ; aucune fibre ne mélange deux ombres géométriques exactes.

**Statut de la borne fibre≤2 :** uniquement `CALCUL EXACT` sur cette population + soutien computationnel externe à cette population ; aucune universalité n'est promue.

## 5. Recalcul du gap sans ancien certificat

On quotient la complémentation globale par la jauge `c_0=0`. Chaque mauvais objet a alors densité `1/8` dans l'espace affine forcé.

Trois problèmes 0/1 sont résolus puis vérifiés par égalités entières exactes :

1. `1-cover` : infeasible dans les cinq cas ;
2. packing disjoint maximal : valeur `7` dans les cinq cas ;
3. `2-cover` : feasible par exactement `16` mauvais objets distincts dans les cinq cas.

Ainsi le nouvel audit reproduit indépendamment le cœur historique :

`ν=7`, `ν_f=8`, pas de partition, mais 2-recouvrement exact à 16 blocs.

## 6. Circuit positif

Pour chaque 2-recouvrement reconstruit, poser

`h_B = 8·1_B - 1`.

Les 16 colonnes satisfont `Σ_B h_B=0`. Le calcul rationnel exact donne dans les cinq cas :

- rang `15` ;
- nullité `1`.

Le support régénéré est donc lui-même un circuit positif primitif à coefficients unitaires.

## 7. Brique de bipartition

La nouvelle brique `BR-OBS-CIRCUIT-01` associe à tout 2-recouvrement exact le multigraphe dont les sommets sont les blocs et dont chaque point de l'univers relie les deux blocs qui le contiennent.

Théorème : une moitié du support partitionne l'univers **ssi** ce graphe est biparti.

Pour les cinq témoins déterministes reconstruits :

- graphe non biparti ;
- cycle impair le plus court de longueur `5`.

Comme le 1-cover global est impossible, aucun 2-recouvrement de ces systèmes ne peut avoir un graphe biparti : sinon une classe de couleur fournirait immédiatement une partition.

## 8. Projection C5

Les supports de 2-recouvrement ne sont pas uniques, conformément à l'audit V17. Le checker déterministe courant trouve :

- cas 1 : `8 lignes + 8 plans` ;
- cas 2 : `8 lignes + 8 plans` ;
- cas 3 : `8 lignes + 8 plans` ;
- cas 4 : `6 lignes + 10 plans` ;
- cas 5 : `8 lignes + 8 plans`.

Ces profils appartiennent aux familles N11 déjà connues ; ils ne prétendent pas être le support canonique de chaque système.

## 9. Falsification et limites

### Réfuté comme stratégie immédiate

La simple capacité de paires ne suffit pas à décrire les circuits : plusieurs paires peuvent fusionner vers le même mauvais objet.

### Non encore prouvé

Conjecture de travail : dans le domaine V19 cohérent `C5,L=3`, chaque mauvais objet propre aurait au plus deux paires préimages. Les tests exacts jusqu'à `N=9`, les cinq `N=11`, la famille cofinale et les tests aléatoires la soutiennent, mais la preuve générale manque. Elle reste hors noyau.

### N=12

Les résumés historiques des 34 ruptures sont présents, mais la liste primaire complète de leurs 34 mappings n'a pas été retrouvée dans cet audit. Aucun nouveau calcul `N=12` n'est donc revendiqué.
