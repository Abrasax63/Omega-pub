# Module Mathématiques

Périmètre prévu : systèmes dynamiques finis, théorie de l'observation, invariants et résultats mathématiques associés.

Chaque résultat doit disposer d'une fiche dédiée construite à partir de [templates/RESULTAT.md](../templates/RESULTAT.md), avec énoncé, hypothèses, preuve, contre-tests et dépendances.

Les résultats étudiés en interne ne sont pas automatiquement considérés comme publiés ou certifiés ici.
