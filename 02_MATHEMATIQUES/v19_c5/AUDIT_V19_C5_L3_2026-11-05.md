# Audit indépendant V19 — C5, L=3

**Date de l'audit source :** 4 novembre 2026  
**Migration documentaire :** 5 novembre 2026  
**Périmètre :** catalogue local C5/D5, témoins de paires et triples, couverture orientée U42.  
**Statut de publication :** EXPÉRIMENTAL — dossier de calcul et de reproduction, pas une certification générale.

## 1. Résultats finis rapportés par le script source

Le script indépendant utilise une propagation directe des contraintes de coloration, sans implémentation DSU/parity-union. Le rapport source annonce :

- 3 341 diagrammes locaux canoniques ;
- 510 diagrammes à ombre propre ;
- 13 classes modulo symétrie diédérale D5 ;
- 14 classes orientées modulo rotations C5 ;
- une seule séparation chirale : D5-06 correspond à C5O-06 et C5O-09.

Les tailles annoncées sont : D5 — quatre classes de taille 4, cinq de taille 8 et quatre de taille 16 ; C5 — quatre classes de taille 4, six de taille 8 et quatre de taille 16.

## 2. Réparation des témoins archivés

### Paires orientées

- 105 lignes historiques.
- 2 lignes ont des paires de témoins dupliquées.
- Les deux lignes sont réparées dans l'export du 4 novembre.
- Les étiquettes de classes sont conservées.

### Triples D5

- 455 lignes historiques.
- 26 lignes ont nécessité une réparation de témoins.
- Les colonnes de classes, les fonctions T et les nombres d'états sont conservés.
- 25 changements touchent pair_b et 3 touchent pair_c (une ligne peut toucher les deux colonnes).
- Après réparation, les trois paires de chaque ligne sont distinctes.

La comparaison directe des deux CSV dans cette consolidation confirme 429 lignes inchangées et 26 lignes modifiées. Elle confirme également que les colonnes autres que pair_b et pair_c sont inchangées.

## 3. Couverture orientée et témoin U42

Les 455 triples archivés sous quotient D5 couvrent 455 des 560 multisets de trois classes orientées C5 possibles. Les 105 combinaisons orientées manquantes contiennent toutes C5O-09.

Le témoin global U42 comporte 42 états et le script examine les 861 paires d'états non ordonnées. Le rapport source annonce 680 paires à ombre propre, au moins 10 témoins par classe orientée, et la construction/vérification des 560 triples orientés avec trois paires distinctes.

Ces énoncés sont des résultats de calcul fini sous les définitions et le code archivés. Ils ne constituent pas, à eux seuls, une preuve générale de la localité V19.

## 4. Limite logique majeure

Le script précise explicitement que la réduction universelle aux préfixes de longueur L+2 dépend du lemme primaire de localité V19. Le présent audit reproduit le catalogue fini et contrôle les témoins dans le périmètre exécuté ; il ne redémontre pas ligne par ligne le lemme général de localité.

Il ne faut donc pas extrapoler les résultats à d'autres valeurs de q ou de L, ni présenter la couverture U42 comme une preuve générale de la classification.

## 5. Provenance, intégrité et reproduction

Les fichiers ont été transférés depuis la branche historique migration/ravi2-ccs-public-2026-11-04 vers cette branche de consolidation sans écraser les originaux. Les CSV sont des exports textuels : leur provenance et leurs Git blob SHA sont documentés dans le README des données. L'identité octet par octet avec les fichiers Library d'origine n'est pas revendiquée.

**Anomalie documentaire détectée pendant la migration :** le fichier JSON source AUDIT_V19_C5_INDEPENDENT_2026-11-04.json sur la branche historique est tronqué (il se termine au milieu de l'objet de réparation, ligne JSON 1000) et n'est pas un JSON valide. Il n'est pas recopié comme rapport valide. Le présent dépôt contient à la place un résumé JSON valide, explicitement distinct du rapport détaillé généré par le script. Le script a été corrigé pour écrire son rapport complet dans le répertoire des données, et non dans research/code/.

Commande de reproduction depuis la racine du dépôt :

```bash
python research/code/audit_v19_c5_independent_2026-11-04.py
```

Cette migration n'affirme pas que la commande a été rejouée dans cette branche. Le statut de reproduction du dossier source indique qu'un job GitHub Actions a précédemment exécuté le script depuis un checkout propre de la branche historique ; ce fait ne remplace pas un nouveau contrôle sur la tête actuelle de la PR.
