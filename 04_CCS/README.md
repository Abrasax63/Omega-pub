# Module CCS

Espace réservé aux définitions, structures et résultats propres à l'axe CCS.

Les acronymes, objets et relations doivent être définis localement. Aucun rapprochement avec un autre domaine ne sera considéré comme une correspondance formelle sans définition et démonstration explicites.

Les contenus non certifiés doivent rester identifiés comme expérimentaux ou conjecturaux.
