# Archives

Espace destiné aux versions et dossiers retirés de l'index actif mais conservés pour assurer la traçabilité.

Toute archive doit indiquer son identifiant, sa version, la raison de son archivage et, si applicable, le dossier qui lui succède.

Ne pas utiliser cet espace pour masquer une réfutation ou supprimer l'historique d'un résultat.
