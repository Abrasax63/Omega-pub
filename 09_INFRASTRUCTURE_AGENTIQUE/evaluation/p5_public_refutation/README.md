# Répétition publique B/C — P5V2-ADV-001

Le fichier freeze.json fixe les consignes avant la rédaction dans un commit
parent. Les deux réponses ont été rédigées successivement dans la même
session ChatGPT, déjà exposée au corrigé. Les notes ne sont pas aveugles.
Cette répétition vérifie l'application du barème sur un exemple.

| Critère gelé | B | C | Vérification |
| --- | --- | --- | --- |
| Verdict proportionné | satisfait | satisfait | Lecture du texte |
| Deux témoins sur le même domaine | satisfait | satisfait | Tables vérifiées par verdict_certificate et comparées au texte |
| Diagnostic du saut logique | satisfait | satisfait | Lecture du texte |

Le budget de longueur de 120 mots a été vérifié par découpage sur les
espaces. Les collisions non injectives sont différentes, toutes deux valides.
Le verdict est une égalité sur les trois critères de cet exemple.
L'effet du routage reste indéterminé, faute de sessions séparées et
d'évaluation indépendante. Aucun usage API, coût ou temps comparable
par bras n'est mesuré dans cet essai.
