# Fiche SV02

## Données

On travaille dans Z/7Z. On définit f(x) = (3*x + 2) mod 7.

## Énoncé

Proposition : f est injective.
Proposition : f est surjective.
Proposition : f possède au moins un point fixe.
Proposition : pour tout x, f(f(x)) = x.
Proposition : l'image de f contient exactement 7 éléments.
Proposition : f possède exactement 1 point fixe.
Proposition : f(f(0)) = 2.
