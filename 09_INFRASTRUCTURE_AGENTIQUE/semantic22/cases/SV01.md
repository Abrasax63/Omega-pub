# Fiche SV01

## Données

On travaille dans Z/6Z. On définit f(x) = (3*x + 5) mod 6.

## Énoncé

Proposition : f possède au moins un point fixe.
Proposition : pour tout x, f(f(x)) = x.
Proposition : l'image de f contient exactement 3 éléments.
Proposition : f possède exactement 1 points fixes.
Proposition : f(f(0)) = 2.
Proposition : f est injective.
Proposition : f est surjective.
