# Fiche SV11

## Données

On travaille dans Z/16Z. On définit f(x) = (9*x + 3) mod 16.

## Énoncé

Proposition : f possède exactement 0 points fixes.
Proposition : f(f(0)) = 14.
Proposition : f est injective.
Proposition : f est surjective.
Proposition : f possède au moins un point fixe.
Proposition : pour tout x, f(f(x)) = x.
Proposition : l'image de f contient exactement 16 éléments.
