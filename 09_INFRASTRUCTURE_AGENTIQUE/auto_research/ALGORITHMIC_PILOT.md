# Omega algorithmic self-improvement: bounded pilot (v0.1)

This is a **first executable experiment**, not proof of independent intelligence or model-driven code synthesis. It deliberately uses an **auditable four-member grammar** to generate different real Python programs for one mathematical kernel:

- Given a finite system `T:X -> X`, observations `pi:X -> Y`, calculate the observed one-step graph `Q`.
- Compute `Q^h` (exact-length observed walks) using four algorithm variants: linear iteration or exponentiation by squaring; full scan or low-bit enumeration of each row.
- Independently compute `R_h` from real trajectories and check `Delta_h = Q^h \\ R_h` for exact equality.

## Design

1. **Generator** `variant_factory.py`: deterministic finite source-code transformations, emits four different executable functions with SHA-256. No LLM involved.
2. **Selection** `runner.py`: scores all four on three preselected *training* seed families for exactness and measured child CPU microseconds; selects the fastest correct program. The selector never receives reserved results.
3. **Execution** `runner.py`: runs *only source generated by the fixed trusted grammar* in a child Python interpreter with `-I -S -B`, temporary working directory, clean environment, wall timeout, CPU/memory/output limits. **This is bounded subprocess isolation, not a security sandbox**: network/filesystem isolation is not enforced. Do not feed arbitrary LLM-generated programs to this runner.
4. **Independent reference** `reference.py`: computes exact-length walks by set-union dynamic programming, separate from generated bitwise code. It independently computes `R_h` and `Delta_h`.
5. **Reserved evaluation**: runs only the chosen winner and fixed `linear-scan` baseline on three other seed families, then calls the unchanged `gate.py` inherited from **PR #83**. The gate prohibits lost correct cases, candidate false answers and cost increases; a pass requires further review and asserts no provenance certificate.

The selected program can equal an existing classical method. `square-scan` is already standard binary exponentiation, included explicitly as the stronger classical comparator. **A speed gain against `linear-scan` does not demonstrate an Omega-specific contribution if the winner is `square-scan`.**

## Reproduce

From `09_INFRASTRUCTURE_AGENTIQUE/auto_research`:

```sh
python3 -m unittest -v test_gate.py test_variant_search.py
python3 runner.py --output pilot-result.json
```

The unit tests enumerate all maps `T` of sizes 1–3, all binary observation colorings, and horizons 0–6 for each of the four implementations. The child process is exercised separately during `runner.py`.

The independent evaluator uses the **same measured cost unit** for both arms: aggregate child-process CPU microseconds, obtained by the parent via `resource.getrusage`. The measurement includes Python startup and is variable across machines/runs. Calls have the same `REPEATS=15` factor. Values and scores are **not** stable benchmark constants.

## Scientific limitations and safety

- Training and holdout use different public pseudorandom seeds in the same repository, not truly secret external data. A determined agent with repository read access can see them; no blind prospective test.
- The manifest hash is produced when the runner evaluates the holdout, rather than timestamped and published independently *before* training. **This does not qualify as genuine preregistration.**
- Costs are measured by the parent process, but GitHub-hosted CPU performance fluctuates. The sample has only three holdout instances and no independent replication or confidence interval.
- Only fixed templates run; there is no unconstrained LLM-generated program, no self-editing of the planner, and no remote sandbox for unknown executables.
- SHA-256 for generated code is logged, but `run_url` and commit metadata are not independently attested by the gate. GitHub Actions is an observable execution, not a scientific certificate.
- The four variants are standard algorithms. No mathematical discovery or general intelligence improvement is claimed.
- Rerunning adaptive selection against the same reserved seeds would invalidate their status as unused holdout; new external, genuinely independent test families are required for any later scientific comparison.
