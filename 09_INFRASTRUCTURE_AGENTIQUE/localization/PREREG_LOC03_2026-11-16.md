## Factorial 2 x 2 design, with separate outcomes

**Factor L = fault-site ranking**, irrespective of repair grammar:
- `S`: broad universe of production Python AST simple statement lines; rank with original seven-rule candidate sites of PR #105 first (same fixed deterministic order), then remaining sites by path and line. This is a hand-engineered static baseline, not a random strawman.
- `T`: **same** universe; rank sites executed by the original failing test via `sys.settrace` in reverse observed event order, then event count, then original static rank. No dynamic insertion of new sites. The traced test is run only in the buggy source, and its overhead is counted separately. Trace validity requires non-truncated line events and original pytest exit=1.

Both select at most **10 distinct sites**. Report the first **exact old-line source diff rank** and top-10 exact hit for S and T. +/-2 proximity is not scored. If no accurate buggy FAIL / fixed PASS pair, abstain.

**Factor G = one candidate patch per chosen site**, irrespective of site strategy:
- `G0`: unchanged original #105 seven-rule generic `candidate_rules`; first deterministic syntactically valid edit at each site, else abstain for that site.
- `G1`: fixed, generic, one-line conditional guard grammar motivated by an *earlier consumed* bug in #111, not invented from these two bugs. For `Assign`, `AugAssign`, `Expr`, `Return` simple one-line statements choose a syntactically valid `if <first deterministic referenced variable>: <statement>` guarded edit; fallback to G0 if not expressible. The guard variable is the assignment target where a single name is present, otherwise the first stable identifier in the statement. No case-specific keywords or candidate mutation after freeze. `G1` may harm performance (it is not an assumed improvement).

Four frozen policies `S-G0`, `S-G1`, `T-G0`, `T-G1`; at most **10 sites and 10 patch tests per policy**, no retries, human choice or models. Both site arms see the same original source/test; both grammar arms see identical selected sites within each site arm. Distinguish patch syntax accepted from genuine regression pass; regression pass is *bounded* and does not establish general correctness.
