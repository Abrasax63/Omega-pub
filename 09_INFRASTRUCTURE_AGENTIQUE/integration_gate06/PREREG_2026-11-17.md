# OMEGA-INTEGRATION-06 — protocole gelé avant code et questions

Date : 2026-11-17. Branche expérimentale empilée sur la PR #149, sans changer `main`, la PR #149 ni le moteur historique (`engine.py`, Git blob `4e4bf62de81bea0eebe1a7a80562e002698d0cd2`).

## Problème / hypothèses falsifiables
La PR #149 (run 44110189657) a montré que quatre nouvelles sources sont invisibles au moteur figé (16/16 abstentions). Une interface générique de registre *versionné* peut charger une source à identifiant inconnu **sans ajouter de condition par identifiant dans le moteur**. Ce test de chargement est distinct de la compréhension de la source.

H1 (intégration) : charger quatre instantanés existants via un manifest `source_id → relative_path + git_blob_sha1`, rejeter une altération/symlink/traversée, et charger en test une cinquième source créée à la volée sans changer le chargeur.
H2 (inférence) : comparer sur 12 nouveaux cas documentés deux appels Qwen2.5-Coder-3B-Instruct Q4_K_M : (A) question seule ; (B) même question + source intégrale avec lignes et Git blob vérifiés. Aucun verdict attendu n'est fourni dans le prompt.
H3 (vérification) : (C) résultat EXACTEMENT identique à B avant contrôle, filtré *après coup* par un oracle indépendant d'énumération finie, qui remplace une affirmation fausse par ABSTENTION. Aucun troisième appel LLM, aucune modification de poids. Un oracle de ce domaine ne prouve ni compréhension de texte ni vérité générale.

## Méthode et budget
- 12 questions nouvelles et fixées AVANT le code d'évaluation, six du système accessible 2 états (BR-ACC-01) et six de sélection de quatre témoins (BR-OBS-CAP-03) ; les faits de départ et les formulations seront figés sur commit distinct.
- 2 appels réels par question, alternance AB/BA. Limite partagée `-c 3072`, `-n 16`, température 0 et modèle + exécutable préalablement épinglés ; 24 appels maximum, vérification finie ajoutée uniquement à B.
- Enregistrer prompts (SHA256 + longueur), sélections et durées puis *seulement ensuite* calculer le corrigé. Le modèle n'obtient que `question` et, pour B, texte source avec citations, jamais `kind`, `word`, `counts`, oracle ou étiquette.
- C est un **filtre à oracle spécialisé disponible seulement pour ce banc**, pas un vérificateur universel ; mesurer le taux de réponses gardées et les erreurs affirmées, sans présenter le zéro erreur éventuel comme une amélioration autonome du LLM.
- Le coût de tokens de contexte n'est PAS égal entre A et B : comparer les coûts réellement mesurés quand ils sont disponibles, sinon indiquer la parité non démontrée. Même limite de génération ≠ même consommation. Les contrôles post-hoc sont facturés séparément en nombre d'instances.
- Le modèle provient du workflow PR #141: `llama.cpp` au commit `5a4afd80779ba51166b59986e61a0bfbb9e1a4c6`, GGUF SHA256 `724fb256bec1ff062b2f65e4569e871ad2e95ab2a3989723d1769c54294730b7`. Pas d'API commerciale. Réutiliser le cache et le workflow CPU.
- Tout résultat demeure DRAFT; pas de modification de `main` ni du registre certifié.

## Métriques / critère
Déclarer pour chaque bras : exact / 12 ; oui/non erronés / 12 ; abstentions / 12 ; coûts (temps, caractères prompts, appels, vérifications). H1 réussit uniquement si nouveaux identifiants, empreintes, traversal et corruptions sont testés. H2 passe uniquement si B a PLUS de réponses correctes que A **et** pas plus d'erreurs affirmées ; sinon résultat nul/négatif. H3 passe son critère de sûreté local si C n'a aucune fausse affirmation, avec couverture non nulle ; attention l'oracle a la vérité du cas et ce n'est pas une équité de données. Aucune généralisation statistique avec 12 cas corrélés.

## Contexte scientifique et limites
Il s'agit d'un protocole construit par le même auteur, avec deux microstructures finies et des sources déjà consultées lors de PR #149. Les douze questions sont nouvelles, **pas les domaines ni les documents**; pas de test aveugle externe. Un cas fini ne certifie pas la théorie générale. Une CI verte valide le code et l'exécution, pas H2. Ne jamais réutiliser ces 12 cas comme un nouveau holdout après observation de leurs résultats.
