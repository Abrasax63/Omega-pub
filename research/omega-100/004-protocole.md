# 004 — Protocole avant exécution

Hypothèse : ignorer les signes mathématiques situés dans des segments de code en ligne fermés par deux suites de backticks de même longueur corrige le cas 003 sans perdre de vrais blocs. Périmètre : segments fermés sur une même ligne ; les citations conservent le texte source au complet. Les suites non appariées restent du texte. Les clôtures mathématiques manquantes et les blocs de code clôturés sur des lignes distinctes sont hors de cette expérience.

Référence expérimentale : lecteur de def8bac9fdafd81422d40c4c45ac3652a6d47e35 avec 002.patch appliqué. Test de réserve figé : deux exemples ordinaires contenant des doubles dollars entre backticks doubles ou triples et un backtick interne, un exemple de crochets LaTeX cités en code, une formule dollar réelle après une ligne avec un backtick non apparié, une formule réelle sur la même ligne qu'un segment de code fermé qui contient un dollar, et un bloc de crochets réel suivant une mention en code de son propre délimiteur. Contrôles : les huit cas des cycles 001–002, les quatre cas du cycle 003 et les 16 tests métier de #179. Oracle : citations littérales, sections et étiquettes mathématiques attendues, avec rendu commun pour les deux versions. Gain strict exigé sur les six nouveaux cas, tous les nouveaux cas conformes, rapport 003 à 4/4 et aucune régression des contrôles. Budget : corpus identique, sans modèle.
