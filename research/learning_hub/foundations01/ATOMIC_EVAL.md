# ATOMIC-EVAL contract (prospective, before any parametric experiment)
Implements only the atomic reading/logic part of FOUNDATIONS-01. Strict JSON
boolean outputs; report validity, exact three-bit reading, decision,
consistency of the model's own reasoning, and joint exactness, per motif
and positive/negative class. Invalid outputs remain in the denominator.
On 128 balanced tasks, a constant negative decision scores 64/128;
the preregistered >=10 percentage point joint gain requires >=13 more
joint successes than base, with both class-specific joint counts improving.
Report supervised and self-generated arms separately and their paired
difference. Render edge list and withheld matrix representations without
answer fields; no actual holdout created here. Test fixtures are disposable.
No promotion from this scorer: 32-item new syntax retention, matched token
and update budgets, split/representation isolation, model and adapter hashes,
and independent seed replication remain prerequisites. No change to the
registered thresholds. No training workflow or model generation triggered
by this patch.
