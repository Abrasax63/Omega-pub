# FOUNDATIONS-01 — preregistration

Status: proposed, not trained. Inspired by Absolute Zero (NeurIPS 2025, https://arxiv.org/abs/2505.03335); this pilot is supervised adaptation, not a reproduction of RLVR.

Reuse SFT01 training infrastructure after interface review. Compare frozen base, oracle-supervised LoRA, and self-generated verified-example LoRA on the same backbone and matched update/token budget. No paid API. No main changes. Disable inherited real-run workflows before enabling any new automatic training. No replay of ATOM08 or TUTOR07 as independent holdouts.

Independent modules: task proposer, schema validator, exact oracle, trainer, evaluator. Proposer can choose bounded graph tasks and representation but cannot set truth labels or access evaluation data. Begin with membership, implication, then positive partitions and negative witnesses. Mix syntax repair replay for retention. Training examples use fresh names, varied ordering and balanced labels. Split by graph isomorphism and representation family; evaluation uses independently generated unseen graphs and withheld sizes. Freeze evaluation manifest before training, keep answers outside prompts and training input. Use an independent oracle by adjacency matrix and connected components, compare against existing exact sensor. Reject duplicates, invalid examples and trivial constant predictors.

Proposed pilot: 256 training items per arm, 64 development, 128 holdout balanced by class, 32 syntax retention items. Fixed seed, matched optimizer steps and token budget, record exact model revision, adapters, hashes, runtime, raw predictions. Success: >=10 percentage point absolute gain over base on joint reading/logic, no more than 5 points loss on syntax retention, improvement on both positive and negative classes, replicate across 3 seeds before promotion. Compare self-generated arm to oracle-supervised arm, not merely base. No tool access during intrinsic evaluation; tool-assisted score reported separately. If resource constraints prevent run, report blocked; no claim of training or gain.
