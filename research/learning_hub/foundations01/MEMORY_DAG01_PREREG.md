# MEMORY-DAG01 — dependency-safe plasticity and dormant reactivation
Freeze before implementation. Synthetic sandbox only, no mutation of existing
scientific libraries. Reconstruct 32 original training solutions and six
mined flat definitions with unchanged COMPOSE-LEARN01; add four nested
compositions of those definitions, one level-3 composition; explicitly label
new nested definitions developer-supplied stress fixtures, not learned.
Versioned state stores active roots, quarantine roots and dependency closure.
Protected evidence (32 original programs plus nested fixture exact results
and negative witnesses) remains in archive, even if not active. Archive
hash and history head verified against separately held trusted values.
Retire root only, preserve any dependency required by remaining roots;
quarantine transitively blocks all dependents, never erase records.
Reject missing dependency, cycle, invalid primitive, altered evidence,
invalid manifest, quarantine bypass and stale manifest head. Rollback is a
new revision; never allow rollback to silently bypass current quarantine.
Simulated recovery: separate read-only backup file, destroy/corrupt ONLY
temporary sandbox live copy, restore bytes and verify trusted hash plus
all evidence; do not claim independent infrastructure or security boundary.
Dormant reactivation: freeze active roots SM and SR if present. Build
12 target tables directly from eligible dormant definitions (six on each
of two fresh primes 31,37) and 12 controls (six per prime) not matching
any archived definition; random seed 20270103; deduplicate within each
prime. Compare primitive-only and active-only exact search to dormant
lookup + active fallback. Lookup checks every eligible dormant expanded
word against full observed table; charge each primitive composition per
candidate before stopping, then normal search cost on nonmatches.
Exclude quarantined dependencies, verify full table independently.
Report reactivation rate, exactness, total charged costs and regressions
on controls; utility requires no lower completion than active-only and
>=15% lower total cost than active-only AND primitive-only, <=10% cost
increase on controls vs active-only. Safety separate: all injected faults
rejected, archive/evidence identical, restore succeeds, correct dependency
closure and quarantine behavior, no incorrect output. This is deliberately
favorable retrieval test, not discovery or broad generalization.
Record full archive in a durable Git commit after verified CI, if possible;
Git commit and CI artifact are not independent-provider backup. No main
change, no real data deletion, no paid API or activation.
