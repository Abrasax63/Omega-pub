## Relation to current experiments
GEM constrains gradient directions using earlier-task memory. A-GEM reduces the number of constraints by using an averaged reference gradient; opposing task-specific conflicts may be hidden by an average. O-LoRA explores orthogonal low-rank subspaces for continual language model learning. PROTECT21/22 are related to GEM but constrain the actual proposed AdamW parameter displacement, using bounded alternating projections rather than asserting an optimal Euclidean projection. None of the published results establishes efficacy on Omega's particular checkpoint, datasets or compute limits.
