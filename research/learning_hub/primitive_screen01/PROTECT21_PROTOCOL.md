## Hypothesis and discriminant
The new objective may interfere with old objectives in shared LoRA parameters. Test against a matched-compute control, not merely a different amount of replay. This is a first-order hypothesis, not an established cause.
Use the exact reproduced PILOT14 adaptive checkpoint and optimizer state; abort before second block unless hash and dev reproduction match. Same new pairs, same balanced old anchor pairs, same order, same initialization, same number of forward/backward operations and optimizer updates in both arms. New-only control computes old gradients but discards them; protection arm modifies proposed update to remove directions that increase any sampled old-skill loss to first order. Four old-skill anchor gradients separate, not a single averaged gradient hiding conflicts. Use current train only; no dev/transfer questions in gradients. Anchors sampled without reference to evaluation outputs. Report actual compute/time; extra gradient storage/linear algebra cost is not identical.
AdamW changes the direction of the raw gradient, so operate on proposed parameter displacement, not raw gradient. For each old loss gradient g, require g dot displacement <= numerical tolerance. If no feasible nonzero protected displacement found by bounded alternating projection, revert to zero displacement and retain the previous optimizer state. For accepted projected displacement, optimizer moments are those of the proposed AdamW step, not a projected-moment optimizer; report this explicitly. Projection is only a local linear condition; finite changes and held-out accuracy can still regress. Preserve optimizer/RNG rollback. Measure old loss before and after actual proposed and corrected updates on anchor examples; held-out accuracy is decisive.
Prospective primary criterion: compared with the frozen pre-second-block control, new skill >=61/64 and >=29/32 complete pairs, no decrease in correct or complete-pair counts for any old skill. Exploratory secondary contrast vs new-only: new skill correct/pairs, per-old-skill deltas, anchor conflict frequencies and displacement norms. No promotion, no automatic hyperparameter search, no independent exam claimed. Replication on another seed and independent curator required.
Stage 1: offline projection kernel checks only. Stage 2: bounded actual checkpoint gradient diagnostic, then reviewed matched-compute learning trial. Do not start stage 2 on fixture success alone.
