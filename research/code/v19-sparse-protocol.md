# V19 — familles plus grandes à faible taux de survie

Base 5509fcfcb36944f5c49792c86a4f1232c4e8e415. Question : le quotient hybride apporte-t-il un gain médian d'au moins 10 % lorsque le taux de survie est ≤ 20 % ? Tester séparément un C4 ou C6 distingué, disjoint d'un C5 et d'un état libre pointant sur un sommet périodique. Toutes les attaches, toutes les paires dont les quatre événements sont distincts, F cohérent. Référence : priority puis projecteur exhaustif sur les survivants. Oracle global exhaustif sur tous les cas. Témoin négatif : C4 pur. Rejouer le garde global sur le témoin à cinq états et la famille C5 comme contrôle historique. Budget ≤ 1 300 requêtes, ≤ 6 500 projections d'oracle, cinq lots par bras en alternance, arrêt à 45 s. Succès uniforme si les deux familles ont zéro erreur, un taux ≤ 20 % et ≥ 10 % de gain ; un taux hors plage rend la famille indéterminée pour ce régime.
