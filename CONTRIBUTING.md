# Contribuer

Merci de contribuer à une discussion précise, reproductible et respectueuse.

## Ouvrir une Issue

Choisir un titre explicite, par exemple :
- [QUESTION] Définition de …
- [ERREUR] Étape … dans …
- [CONTRE-EXEMPLE] Énoncé …
- [REPRODUCTION] Calcul …
- [LITTÉRATURE] Résultat antérieur sur …

Inclure le fichier, la version et les passages concernés. Ajouter un raisonnement ou une source vérifiable lorsque c'est possible.

## Proposer une Pull Request

- Limiter chaque PR à un changement cohérent.
- Expliquer le problème traité et la raison de la modification.
- Ajouter les références et tests utiles.
- Ne pas remplacer silencieusement un résultat antérieur.
- Ne pas marquer un résultat comme démontré sans preuve et examen appropriés.

## Données et sécurité

Ne pas publier de données personnelles, secrets, clés d'API, mots de passe, données sous licence incompatible ou documents dont la diffusion n'est pas autorisée.

## Code et calculs

Fournir les versions, dépendances, commandes, entrées et sorties nécessaires à la reproduction. Distinguer clairement le code fourni du code effectivement exécuté et vérifié.
