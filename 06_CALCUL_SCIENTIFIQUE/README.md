# Module Calcul scientifique

Ce module rassemble les programmes, simulations, données partageables et procédures de reproduction.

Tout dossier de calcul doit préciser les versions, dépendances, entrées, commandes, sorties et limites. Une simulation n'est pas une preuve générale.

Ne publier aucune donnée personnelle, secret ou donnée dont les droits de diffusion ne sont pas établis.
