# Module Informatique théorique

Périmètre prévu : SAT, complexité, réductions et questions liées à P/NP.

Les résultats doivent être formulés indépendamment des analogies avec d'autres modules. Toute affirmation concernant P versus NP doit préciser son énoncé, ses hypothèses et son niveau réel de preuve.

Aucun résultat de résolution de P versus NP n'est déclaré par la création de ce module.
