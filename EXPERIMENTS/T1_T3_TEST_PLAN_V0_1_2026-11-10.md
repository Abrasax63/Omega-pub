## 1. Objectif et périmètre

Ce plan vérifie que les tâches synthétiques sont déterminées (T1) ou sous-déterminées (T3) conformément à leurs données publiques, que les oracles recalculent les résultats indépendamment du générateur, et qu'aucune information privée n'est exposée.

Il ne mesure pas la performance de ChatGPT, d'Omega fixe ou d'Omega adaptatif. Il ne teste pas les résultats mathématiques L+1/L+2.

## 2. Environnement de référence

- Python 3.12.
- Bibliothèque standard uniquement (`unittest`, `json`, `hashlib`).
- Répertoire : `EXPERIMENTS/generators/`.
- Commande depuis la racine du dépôt :

```bash
python -m unittest discover -s EXPERIMENTS/generators -p 'test_*.py' -v
```

Cette commande est celle du workflow GitHub Actions `.github/workflows/t1-t3-generators.yml`.

## 7. Contrôles négatifs et interprétation

Un test de mutation est réussi si le validateur renvoie explicitement `False` pour l'instance modifiée. Une exception non prévue ou un échec d'exécution n'est pas assimilé à un rejet contrôlé.

Le validateur de cohérence garantit que le texte transmis est le rendu canonique des paramètres publics fournis. Il ne prouve pas que les paramètres eux-mêmes correspondent à une spécification métier externe ; cette vérification relève de l'oracle et de la revue du générateur.

## 8. Procédure d'exécution et verdict

1. Exécuter la commande de référence dans Python 3.12 via CI.
2. Archiver le commit SHA, le run, les logs, la version Python et la commande.
3. Vérifier les résultats des tests positifs et négatifs.
4. Ajouter les contrôles restants de la section 6.
5. Faire une revue indépendante du contrat, des rendus et des oracles.
6. Seulement après validation, geler un lot pilote avec manifestes public/privé séparés et empreintes SHA-256.

- **PASS logiciel :** tous les tests requis passent et les mutations prévues sont rejetées explicitement.
- **FAIL logiciel :** au moins un invariant ou contrôle négatif échoue.
- **INDÉTERMINÉ :** test non exécuté, environnement indisponible ou résultat incomplet.
- **Non évalué :** comparaison des systèmes A/B/C ; aucun score de performance ne peut être attribué par ce plan.

Ne pas assimiler PASS logiciel à une validation du benchmark ou à une preuve d'avantage Omega.
