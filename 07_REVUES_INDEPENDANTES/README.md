# Revues indépendantes

Ce module rassemble les rapports de revue, objections, contre-exemples et réponses documentées.

Chaque revue doit identifier le résultat et sa version exacte. Les critiques des auteurs et les vérifications indépendantes doivent être distinguées.

Le protocole de revue applicable est [REVIEW_PROTOCOL.md](../REVIEW_PROTOCOL.md).
